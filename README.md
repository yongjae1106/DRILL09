# DRILL09 작업 계획서 - 방향키로 소년 이동시키기

이 문서는 `move_character.py`를 **어떤 방식으로, 어떤 순서로 구현할지** 정리한 작업 계획이다.
코드는 아래 순서대로 한 단계씩 작성하고, 단계마다 커밋한다.

---

## 1. 작업 원칙
1. **한 커밋 = 한 가지 변경.** 기능 추가, 리팩토링, 문서 수정을 한 커밋에 섞지 않는다.
2. **모든 커밋은 실행 가능한 상태로 남긴다.** 중간 커밋을 체크아웃해도 창이 뜨고 ESC로 종료되어야 한다.
3. **작은 기능부터 쌓는다.** 화면 → 배경 → 캐릭터 → 애니메이션 → 좌우 이동 → 상하 이동 → 경계 처리 → 정리 순서로 진행한다.
4. 커밋할 때마다 직접 실행해서 해당 단계의 동작을 확인한 뒤 다음 단계로 넘어간다.

## 2. 커밋 메시지 규칙
`<타입>: <무엇을 했는지>` 형식을 쓰고, 한글로 작성한다.

| 타입 | 용도 |
| --- | --- |
| `docs` | README 등 문서 작성/수정 |
| `feat` | 새로운 기능 추가 |
| `refactor` | 동작은 그대로 두고 코드 구조만 정리 |
| `fix` | 버그 수정 |

예시: `feat: 좌우 방향키 입력 처리`

## 3. 리소스 분석 결과
- `TUK_GROUND.png` : 1280 x 1024 → **캔버스 크기를 배경과 같게** 열고 화면 중앙에 그린다.
- `animation_sheet.png` : 한 프레임 100 x 100, 가로 8프레임, 세로 4줄

| clip_draw 의 bottom 값 | 동작 |
| --- | --- |
| 300 | 오른쪽을 보는 IDLE |
| 200 | 왼쪽을 보는 IDLE |
| 100 | 오른쪽으로 달리기 |
| 0 | 왼쪽으로 달리기 |

## 4. 설계

### 4-1. 상태 변수
| 변수 | 의미 |
| --- | --- |
| `x, y` | 캐릭터 위치 (시작은 화면 중앙) |
| `dir_x` | 좌우 이동 방향 (-1, 0, 1) |
| `dir_y` | 상하 이동 방향 (-1, 0, 1) |
| `face` | 바라보는 방향 (1: 오른쪽, -1: 왼쪽) |
| `frame` | 현재 애니메이션 프레임 (0 ~ 7) |
| `running` | 게임 루프 실행 여부 |

### 4-2. 키 입력 처리
- `SDL_KEYDOWN` 에서 방향 값을 **더하고**, `SDL_KEYUP` 에서 **빼는** 방식을 쓴다.
  - 예) → 누르면 `dir_x += 1`, → 떼면 `dir_x -= 1`
  - 왼쪽·오른쪽 키를 동시에 눌렀다가 하나만 떼도 방향이 올바르게 남는다.
- 상하도 같은 방식으로 `dir_y` 를 처리한다.
- `SDL_QUIT` 또는 ESC 로 종료한다.

### 4-3. 애니메이션 선택 규칙
1. `dir_x` 가 0이 아니면 `face` 를 `dir_x` 방향으로 갱신한다.
2. **위/아래로만 움직일 때는 `face` 를 바꾸지 않는다** → 기존 방향 유지.
3. 줄 선택
   - 멈춤(`dir_x == 0 and dir_y == 0`) → IDLE 줄 (`face` 에 따라 300 / 200)
   - 이동 중 → 달리기 줄 (`face` 에 따라 100 / 0)

### 4-4. 화면 경계 처리
- 캐릭터 크기의 절반만큼 안쪽을 경계로 잡는다.
  - x : 50 ~ 1230, y : 50 ~ 974
- 위치를 갱신한 뒤 `clamp(최소, 값, 최대)` 로 경계 밖으로 나가지 않게 고정한다.

### 4-5. 최종 코드 구조
```
상수 정의 (화면 크기, 스프라이트 정보, 속도, 경계)
리소스 로드 (open_canvas, load_image)
handle_events()     : 키 입력 → dir_x, dir_y, running 갱신
update_character()  : face 갱신, 위치 이동, 경계 제한, 프레임 증가
draw_character()    : 상태에 맞는 줄을 골라 clip_draw
메인 루프           : clear → 배경/캐릭터 그리기 → update_canvas → 이벤트 → 갱신 → delay
close_canvas()
```

## 5. 커밋 단계 (총 20단계)
| # | 커밋 메시지 | 확인할 동작 |
| --- | --- | --- |
| 1 | `docs: 작업 계획서 README 작성` | 이 문서 |
| 2 | `feat: pico2d import 및 화면 크기 상수 정의` | 실행 오류 없음 |
| 3 | `feat: 배경 크기에 맞춰 캔버스 열기/닫기` | 1280x1024 창이 열렸다 닫힘 |
| 4 | `feat: 배경 이미지 TUK_GROUND 로드 및 출력` | 배경이 보임 |
| 5 | `feat: 메인 게임 루프와 종료 이벤트(QUIT, ESC) 처리` | 창이 유지되고 ESC/X로 종료 |
| 6 | `feat: 캐릭터 스프라이트 로드 및 화면 중앙에 출력` | 중앙에 소년 한 프레임 |
| 7 | `feat: 프레임을 순환시켜 스프라이트 애니메이션 적용` | 소년이 제자리에서 움직임 |
| 8 | `refactor: 스프라이트 프레임 크기/개수를 상수로 정리` | 동작 변화 없음 |
| 9 | `feat: IDLE 애니메이션 적용` | 오른쪽 IDLE 애니메이션 재생 |
| 10 | `feat: 좌우 방향키 입력 처리 (KEYDOWN)` | 키 입력 시 dir_x 변경 |
| 11 | `feat: 방향키를 떼면 정지 (KEYUP)` | 키를 떼면 dir_x 복귀 |
| 12 | `feat: 이동 속도 상수 추가 및 좌우 이동` | ←/→ 로 좌우 이동 |
| 13 | `feat: 바라보는 방향에 따른 좌우 달리기 애니메이션` | 방향에 맞는 달리기 모습 |
| 14 | `feat: 바라보는 방향에 따른 IDLE 애니메이션` | 멈추면 보던 방향 IDLE |
| 15 | `feat: 상하 방향키 입력 처리` | ↑/↓ 입력 시 dir_y 변경 |
| 16 | `feat: 상하 이동 및 기존 방향 유지` | 위아래 이동 시 보던 방향 유지 |
| 17 | `feat: 화면 경계 상수 정의` | 동작 변화 없음 |
| 18 | `feat: 화면 경계에서 더 이상 진행하지 않도록 제한` | 가장자리에서 멈춤 |
| 19 | `refactor: update / draw 함수로 코드 구조 정리` | 동작 변화 없음 |
| 20 | `docs: README에 완료 체크 및 실행 방법 추가` | 문서 최종 정리 |
